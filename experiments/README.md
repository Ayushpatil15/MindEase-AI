# Machine Learning Experiments

This directory contains standalone experiment scripts and benchmark results evaluated during model development and deployment optimization for MindEase AI.

## Files Overview

### 1. `phase56_experiment.py`
- **Purpose**: Trains and evaluates the Phase 5.6 Challenger model against the baseline CNN architecture on the FER-2013 dataset.
- **Details**: Handles data loading, class re-mapping, model training with early stopping, classification reports, confusion matrices, and parameter comparisons.

### 2. `phase56_latency.py`
- **Purpose**: Standalone inference latency benchmarking tool for Phase 5.6 models.
- **Details**: Measures single-batch execution time (mean and 95th percentile latency in milliseconds) across CPU and GPU devices using warm-up and timed inference iterations.

### 3. `phase58_experiment.py`
- **Purpose**: Candidate C (Tiny Residual / Depthwise Separable Hybrid CNN) experiment pipeline.
- **Details**: Implements an ultra-compact hybrid CNN architecture designed for edge deployment. Trains the model on FER-2013, measures parameter counts, evaluates validation and test metrics (accuracy, macro F1, weighted F1, per-class F1), benchmarks CPU inference latency, and checks automated promotion gates.

### 4. `phase58_results.json`
- **Purpose**: Machine-readable output summary generated by `phase58_experiment.py`.
- **Details**: Captures full test metrics, per-class precision/recall/F1, confusion matrices, parameter counts (~41k vs ~620k baseline), model sizes, and promotion gate results for Candidate C vs Baseline.

### 5. `phase59_experiment.py`
- **Purpose**: Deployment and inference optimization pipeline converting trained Keras models to TensorFlow Lite (TFLite).
- **Details**: Converts models to multiple quantization formats (FP32, FP16, Dynamic Range INT8, Full INT8 with representative dataset calibration), verifies numerical fidelity with cosine similarity, runs multi-threaded latency sweeps (1, 2, 4 threads), and evaluates holdout accuracy.

### 6. `phase59_results.json`
- **Purpose**: Comprehensive results log produced by `phase59_experiment.py`.
- **Details**: Records conversion sizes, latency across thread configurations, cosine similarity against unquantized models, holdout test accuracy, and promotion gate criteria for all evaluated candidates and quantization variants.
